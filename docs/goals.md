# Project goals (priority order)

1. **Learn a new programming stack** — TypeScript, React Native/Expo,
   mobile dev patterns (camera, GPS, geospatial math). This is the
   main point of the project.
2. **Learn to vibe-code** — practice working effectively with an AI
   coding agent (Claude Code): giving good direction, reviewing
   generated code critically, keeping the agent in scope.
3. **End up with an app I'd actually use** — nice to have, lowest
   priority. Don't sacrifice #1 or #2 to chase this.

## Secondary motivation: job search
Currently job-hunting for software developer / adjacent roles
(background: Python, R, SQL, data science; prior research roles at
Harvard, Duke, HSE). This project is meant to double as a portfolio
piece. TypeScript + React Native was chosen partly because it reads
as three things to employers at once — JS/TS proficiency, React (used
far beyond mobile), and mobile development — rather than a narrower,
mobile-only skill like Flutter/Dart would.

## Non-goals for now
- Building a product to acquire real users or compete with existing
  apps (GPS Trail Map, You Are Here, etc.) — those exist, have seen
  near-zero traction after years on the store, and that's fine; this
  project isn't optimizing for market success.
- Multi-platform polish, backend structure, or anything that doesn't serve
  goals 1–3 above.
