# Project Structure

Quick-reference glossary of every tracked file. "Hand-edit" means you
own it; "tooling-managed" means it's generated or updated automatically
and direct edits are usually wrong.

---

## Repo root — Git / repo config

| File | What it is | Managed by |
|------|-----------|------------|
| `.gitattributes` | Tells Git to store all text files with LF line endings. | Hand-edit |
| `.gitignore` | Root-level patterns Git ignores (node_modules, build output, logs, env files, etc.). | Hand-edit |
| `LICENSE` | MIT licence for the repo. | Hand-edit |

---

## Repo root — Project docs

| File | What it is | Managed by |
|------|-----------|------------|
| `README.md` | Human-facing intro: what the project is, current status, stack, doc index. | Hand-edit |
| `CLAUDE.md` | Context and working rules for Claude Code sessions — goals, stack, conventions, Definition of Done. | Hand-edit |
| `docs/goals.md` | Project goals and priority order (learning over shipping). | Hand-edit |
| `docs/mvp-scope.md` | Phase-by-phase feature scope; what is and isn't in each phase. | Hand-edit |
| `docs/setup-log.md` | Chronological log of setup/scaffolding commands actually run, with dates. | Hand-edit (append-only; Claude Code appends after successful commands) |
| `docs/workflow.md` | Personal process notes for discussing, delegating, and reviewing work with Claude Code. | Hand-edit |

## phase0/ — Git config

| File | What it is | Managed by |
|------|-----------|------------|
| `phase0/.gitignore` | Vite's standard ignore rules for the sub-project (dist, node_modules, editor dirs, etc.). | Tooling-managed (generated by `npm create vite`); safe to extend by hand |

---

## phase0/ — npm / TypeScript config

| File | What it is | Managed by |
|------|-----------|------------|
| `phase0/package.json` | Declares dependencies (`leaflet`), dev dependencies (`vite`, `typescript`, `@types/leaflet`), and scripts (`dev`, `build`, `preview`). | Hand-edit (for deps/scripts); `npm` rewrites the `version` field |
| `phase0/package-lock.json` | Exact dependency tree lockfile — ensures reproducible installs. | Tooling-managed (`npm install`); commit it, never hand-edit |
| `phase0/tsconfig.json` | TypeScript compiler config: bundler mode, strict linting rules, targets ES2023. | Hand-edit |

---

## phase0/ — App source

| File | What it is | Managed by |
|------|-----------|------------|
| `phase0/index.html` | Vite's HTML entry point; loads `src/main.ts` via a `<script type="module">` tag. | Hand-edit |
| `phase0/src/main.ts` | TypeScript entry point — currently the Vite placeholder; will become the Phase 0 app. | Hand-edit |
| `phase0/public/favicon.svg` | Static asset served as-is by Vite (the default Vite logo). | Hand-edit / replace |
